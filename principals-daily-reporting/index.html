A Principal's own daily report for their school — adapted from a standalone Report_2.html prototype. Everything on this tab is now wired to real data (see apps-script/principal-dr.gs): Month Activities merges the School's official Calendar with Planned Activities (tagged "School Specific"); Support Session count is a simple "SS"-tagged Calendar count, not yet cross-referenced against Teacher SS submissions; Tasks Completed suggestions come from the nearest prior working day's Tasks for Tomorrow, plus any still-open Planned Activity due today or overdue; Planned Activities and Submit both persist to the "LMCS Principal DR — Daily Reports" Sheet. Pick any date in the Date field (or use its refresh button) to load that day's report if one was already submitted.
